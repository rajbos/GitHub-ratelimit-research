How to use: This dashboard shows your GitHub API rate limit usage sampled every 15 minutes. Select a time window on either chart to rank the workflows that were active in it and find what could be behind high usage. Data is stored in the data branch of this repository. Saving a GitHub PAT above lets you fill gaps in that data from the GitHub API.
